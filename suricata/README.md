# «Suricata»

---
  
### Задание 1  
  
Напишите правило для детектирования Xmas-сканирования.  
  
`alert tcp any any -> $HOME_NET any (msg:"Xmas scan detected"; flags:FPU; sid:1000001; rev:1;)`. 
  
alert        — создание алерта  
tcp          — проверка TCP-трафика  
any any      — любой источник и любой порт источника  
$HOME_NET any — сеть, любой порт назначения  
msg          — текст сообщения  
flags:FPU    — поиск флагов FIN, PSH, URG (признаки Xmas scan)  
sid          — уникальный номер пользовательского правила  
rev          — версия правила  
  
Правило срабатывает на TCP-пакеты с одновременно установленными флагами FIN, PSH и URG. Такая комбинация характерна для Xmas-сканирования, которое используется для определения открытых/закрытых портов.  

### Задание 2  
  
Напишите правило для детектирования стороннего трафика, передающегося службой DNS.  
  
`alert dns any any -> any any (msg:"Possible non-DNS traffic over DNS detected"; dns.query; content:"."; dns.query; pcre:"/^[A-Za-z0-9+\/]{40,}\./"; sid:1000002; rev:1;)`  
  
alert — создание алерта  
dns — проверка DNS-трафика  
any any — любой источник и любой порт источника  
-> any any — любой получатель и любой порт назначения  
msg — текст сообщения  
dns.query — анализируем DNS-запрос  
pcre — регулярное выражение для поиска подозрительного шаблона в DNS-запросе  
[A-Za-z0-9+\/]{40,} — поиск длинной строки из букв, цифр и символов кодирования  
\. — строка должна заканчиваться точкой перед доменной зоной или следующей частью домена  
sid — уникальный номер пользовательского правила  
rev — версия правила  
  
Правило срабатывает на DNS-запросы с длинными подозрительными поддоменами, похожими на закодированные данные. Это может указывать на передачу стороннего трафика через службу DNS, например DNS tunneling.
